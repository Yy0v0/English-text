## 🔄 题库双向同步工作流

题库数据在 `题库数据.js` 和 `题库.xlsx` 两份文件中互相同步：

```
┌─────────────────┐    build_xlsx.py    ┌─────────────────┐
│   题库数据.js    │ ← ───────────────→ │    题库.xlsx    │
│ (游戏使用此文件) │   同步题库.py       │ (用Excel编辑)   │
└─────────────────┘ ←───────────────→  └─────────────────┘
```

### 方式一：直接修改 JS 文件（最简单）

1. 用文本编辑器打开 `题库数据.js`
2. 找到 `const QUESTION_BANK = [...]` 部分
3. 按格式添加 / 修改 / 删除题目
4. **直接刷新游戏页面**即可看到更改

### 方式二：通过 Excel 编辑（适合大量编辑）

1. **运行 `build_xlsx.py`**（双击或命令行 `python build_xlsx.py`）
   → 从 `题库数据.js` 导出生成 `题库.xlsx`

2. **用 Excel 打开 `题库.xlsx`**，在「题库」Sheet 中编辑题目

3. **运行 `同步题库.py`**（双击或 `python 同步题库.py`）
   → 将 Excel 的修改同步回 `题库数据.js`

4. **刷新游戏页面**即可看到新题目

## 📝 题库数据格式

每道题目的格式如下：

```javascript
{type:'单词', diff:'low', q:'「苹果」的英文是？',
 options:['apple','orange','banana','grape'],
 ans:0, explain:'apple = 苹果'}
```

| 字段 | 说明 | 示例 |
|------|------|------|
| `type` | 题型 | `'单词'` / `'语法'` / `'翻译'` |
| `diff` | 难度 | `'low'` / `'high'` / `'chu1'` / `'chu2'` |
| `q` | 题目文字 | `'「苹果」的英文是？'` |
| `options` | 四个选项（数组） | `['apple','orange','banana','grape']` |
| `ans` | 正确答案序号 | `0` = A, `1` = B, `2` = C, `3` = D |
| `explain` | 答题后显示的解析 | `'apple = 苹果'` |

### 难度对照

| diff 值 | 含义 |
|---------|------|
| `low` | 小学低年级（1-3年级） |
| `high` | 小学高年级（4-6年级） |
| `chu1` | 初一（七年级） |
| `chu2` | 初二（八年级） |

## 📊 XLSX 表格各列说明

| 列名 | 说明 | 填写规范 |
|------|------|---------|
| `type` | 题型 | 填 `单词` / `语法` / `翻译` |
| `diff` | 难度 | 填 `low` / `high` / `chu1` / `chu2` |
| `q` | 题目 | 填题目文字 |
| `options` | 选项 | 四个选项，**英文逗号**分隔，顺序对应 A/B/C/D |
| `ans` | 正确答案 | 填 `0`(A) / `1`(B) / `2`(C) / `3`(D) |
| `explain` | 解析 | 答对后显示的文字 |

> ⚠️ `ans` 列必须填数字 0-3，不是填字母 A/B/C/D。

## 🔧 常见问题

**Q：改了 xlsx 但游戏没变化？**
请确认运行了 `同步题库.py`，将修改同步回 `题库数据.js`，然后刷新游戏页面。

**Q：运行脚本报缺少 openpyxl？**
在命令行运行：`pip install openpyxl`

**Q：如何增加新成就？**
在 HTML 中找到 `ACHIEVEMENTS` 数组，按现有格式添加。稀有度用 `rarity` 字段（common/uncommon/rare/epic/legendary）。

**Q：如何增加新商品？**
在 HTML 中找到 `SHOP_ITEMS` 数组，按格式添加。类型 `type` 分为 `decor`（装扮）和 `consumable`（消耗品）。
