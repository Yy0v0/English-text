# 英语闯关游戏

面向中小学生的趣味英语学习网页游戏，纯前端实现，**双击 HTML 文件即可开始玩**，无需安装任何环境。

作者：子悦 · 2026

## 仓库内容

| 路径 | 说明 |
| --- | --- |
| `英语闯关游戏.html` | 游戏主程序（「星耀探秘」版本，2026-04-26，当前最新） |
| `yyxx/英语闯关游戏.html` | 游戏主程序（「英语闯关 · 星耀学院」版本，2026-04-25） |
| `yyxx/题库数据.js` | 题库源数据，**游戏实际读取此文件** |
| `yyxx/题库.xlsx` | 题库表格，方便用 Excel 批量编辑 |
| `yyxx/build_xlsx.py` | 由 `题库数据.js` 导出 `题库.xlsx`（JS → XLSX） |
| `yyxx/同步题库.py` | 把 `题库.xlsx` 的修改同步回 `题库数据.js`（XLSX → JS） |
| `yyxx/制作者说明文档.md` | **完整制作者手册**：题库格式、XP 规则、段位与成就系统 |
| `yyxx/update_shortcut.ps1` | 更新桌面快捷方式的辅助脚本 |

> `英语闯关游戏_new.html` 是一个 0 字节的空文件，应该是历史遗留，保留原样未删除。

## 玩法

1. 下载仓库（或用 GitHub 的 Download ZIP）
2. 双击 `英语闯关游戏.html`
3. 浏览器直接开玩，进度保存在浏览器 localStorage（键名 `starAcademy_v4`）

## 题库怎么改

两条路，详见 [`yyxx/制作者说明文档.md`](yyxx/制作者说明文档.md)：

- **小改**：直接编辑 `yyxx/题库数据.js` 里的 `QUESTION_BANK` 数组，刷新页面即可
- **大改**：跑 `build_xlsx.py` 生成 Excel → 编辑 → 跑 `同步题库.py` 回到 JS

依赖：`pip install openpyxl`
